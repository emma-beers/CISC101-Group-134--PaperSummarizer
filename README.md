# CISC101-Group-134--PaperSummarizer
Paper Summarizer 3

This repository contains a modular, rule-based system prompt design for a Research Paper Summarizer. The system takes academic papers as the input and produces summaries, tables, glossary terms, and quality-control checks—while maintaining strict guardrails against hallucination.

The summarizer has been tested for the paper “Attention Is All You Need”.
